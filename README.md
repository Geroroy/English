# 10분 영어 — 회화에서 영작까지

하루 **10분**, 실생활 영어 표현을 익히고 최종적으로 **스스로 영작**할 수 있도록 설계된 웹 앱(PWA)입니다.
설치나 빌드 없이 브라우저에서 바로 실행되고, 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 하루 10분 학습 흐름

| 단계 | 시간 | 내용 |
|---|---|---|
| 🔁 복습 | 1분 | 지난 레슨 표현을 간격 반복(1·3·7·14·30·60일)으로 다시 꺼내 말하기 |
| 💡 핵심 표현 | 3분 | 오늘의 패턴 + 실생활 표현 3개, 원어민 음성 듣기 / 🎤 따라 말하기 점수 |
| 💬 대화 | 1분 | 패턴이 실제로 쓰이는 짧은 상황 대화 |
| 🧩 문장 만들기 | 2분 | 한국어 → 영어 단어 조립으로 어순 익히기 |
| ✍️ 작문 | 3분 | 오늘 패턴으로 직접 쓰기 → 자가 체크리스트 → 예시 답안과 비교 → 고쳐 쓰기 |

상단 타이머가 10분을 세어 주고, 끝나면 연속 학습일(🔥)이 올라갑니다.

## 작문 단계 (최종 목표: 자유 작문)

- **Lv.1 한 문장 쓰기** (Day 1–7): 주문, 부탁, 계획, 경험, 제안, 길 묻기
- **Lv.2 2~3문장 연결하기** (Day 8–14): 의견, 이유, 감정, 습관, 허락, 과거 이야기, 조언
- **Lv.3 짧은 단락 쓰기** (Day 15–20): 비교, 문제 해결, 약속 잡기, 감사·사과, 가정, 일기
- **Lv.4 자유 작문**: 20개 레슨을 마치면 매일 새로운 주제로 4문장 이상 자유 작문 + 복습

쓴 글은 모두 **작문노트**에 저장되어 고치기 전/후를 비교하고, 전체를 복사해 둘 수 있습니다.

## 실행

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

GitHub Pages 등 아무 정적 호스팅에 그대로 올려도 됩니다. 학습 기록은 브라우저(localStorage)에 저장됩니다.

- 음성 듣기: 대부분의 브라우저 지원 (Web Speech API)
- 🎤 따라 말하기: 음성 인식을 지원하는 브라우저(Chrome, Edge, Safari 등)에서만 표시

## 구조

```
index.html            화면 틀
styles.css            스타일 (다크 모드 지원)
js/lessons.js         커리큘럼 데이터 (레슨 20개 + 자유 작문 주제)
js/scenes.js          문장별 그림 장면(이모지)과 레슨 배경색
js/core.js            순수 로직: 연속 학습일, 간격 반복, 작문 체크, 말하기 유사도
js/app.js             화면과 학습 흐름
sw.js                 오프라인 캐시
tests/core.test.mjs   로직·데이터 테스트
docs/design-brief.md  "오늘의 문장" 화면 디자인 브리프
```

레슨을 추가하려면 `js/lessons.js`에 같은 형식의 객체를 넣으면 됩니다.

## 테스트

```bash
node --test tests/*.test.mjs
```
